The open-source SDK for building grounded cybersecurity agents.

Tulip is a Python SDK for security agents that audit cloud posture, triage alerts, and fingerprint AI infrastructure — and only ship a finding when the evidence clears the bar. The model gathers and proposes; the SDK decides what's trustworthy.

pip install tulip-agents

from tulip.security import create_soc_analyst, ground_report, is_finding

analyst = create_soc_analyst(model="anthropic:claude-sonnet-4-6")
result = await analyst.run("Audit this account's IAM posture.")

for finding in ground_report(result.output):
    if is_finding(finding):        # evidence cleared the bar → ships
        print(finding.severity, finding.title, finding.gsar_score)
    else:
        print("withheld:", finding.reason)  # ungrounded → abstains

Why Tulip

Findings you can trust, by construction

A security Finding can only be produced from evidence that clears the grounding threshold. Below the bar, the agent abstains and records why. An ungrounded finding is a false positive by construction — there's no public path that builds one. That's the difference between an AI-security SDK and an agent framework with a security demo.
